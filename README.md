# TARKIT Demo

[Open the interactive demo](https://tarekezzat01.github.io/tarkit-demo/)

A sales and customer-success workspace for B2B teams in Saudi Arabia and the GCC. Explore three role environments, light/dark themes, CRM and CSM boards, analytics, forecasts and GTM planning.

All companies, contacts, opportunities and activities are fictional. Changes stay in the current browser session. This public build has no production database connection and does not call AI providers. No login is required.

Published from the isolated demo build on 22 September 2026. GitHub Pages serves the main branch root.
